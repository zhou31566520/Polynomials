三、配置化爬虫核心设计（最关键）
配置文件格式（JSON）
你只需要为每个网站写一份配置，爬虫就能自动工作，示例：
json
{
  "site_name": "笔趣阁",
  "domain": "https://www.biquge.com",
  "book_info": {
    "title": "#info h1::text",
    "author": "#info p::text",
    "cover": "#fmimg img::attr(src)",
    "description": "#intro::text"
  },
  "chapter_list": "#list dd a",
  "chapter_title": "::text",
  "chapter_url": "::attr(href)",
  "content": "#content::html",
  "content_filter": ["&nbsp;", "<script>", "广告"]
}
✅ 规则解释：用 CSS 选择器定位网页元素，爬虫自动提取数据，适配任意小说网站。
爬虫工作流程
加载网站配置文件
输入小说主页 URL
自动提取小说基础信息
爬取完整章节列表
逐章下载内容并净化
保存为标准格式到本地
