# Worker
## 项目介绍
    这是一个基于Python的项目，部署在服务器上， 用于执行制定代码或脚本任务
## 项目功能
    1. 启动的时候，向任务管理服务器注册自己， 并标记自己的状态为“空闲”
    2. 通过接收任务管理服务器发送的任务， 并向任务管理服务器报告自己的状态为“忙碌”
    3. 根据任务信息，获取任务相关代码或脚本（http下载，或者git下载）
    4. 根据任务信息， 选择合适的任务执行方式（不同代码语言）
    5. 任务执行完成后，向任务管理服务器报告任务执行结果

## 项目架构
    1. 任务管理服务器：负责接收任务， 分配任务给不同的Worker， 并接收Worker的任务执行结果
    2. Worker：负责执行任务， 并向任务管理服务器报告任务执行结果
    3. 数据库：用于存储任务信息， 任务执行结果， 任务状态等
